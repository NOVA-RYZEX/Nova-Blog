# Security Policy

## Supported versions

Security support applies to the active main branch while the project is under active development.

## Reporting a vulnerability

Do not open a public issue for sensitive security reports.

Instead, contact the maintainers privately through the project security channel or GitHub security advisories if enabled.

## What to include

Please include:

- a clear summary of the issue
- steps to reproduce
- affected files or components
- potential impact
- any suggested fix or mitigation
